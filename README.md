**Full-Stack Web Application | Symfony 6.4 | PHP 8.1 | SQLite**

## 📌 Professional Summary

Developed a comprehensive music album review platform from scratch, demonstrating advanced proficiency in modern PHP development, Symfony framework architecture, and full-stack web application design. ## 🎯 Project Overview

A feature-rich web platform enabling users to discover, review, and rate music albums across multiple genres. Built with Symfony 6.4 following MVC architecture and SOLID principles, the application handles complex user interactions, role-based access control, and sophisticated data relationships while maintaining clean, maintainable code.

**Live Demo Features:**
- 🔐 Multi-role authentication system (User/Moderator/Admin)
- 📝 CRUD operations for albums and reviews
- 🔍 Advanced search with multi-criteria filtering
- 📸 Secure file upload system with validation
- 👤 Complete user profile management
- 📊 Dynamic rating aggregation system
- 📱 Responsive, modern UI with Bootstrap 5
